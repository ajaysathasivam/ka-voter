
## Setup Instructions

### 1. Clone the repository

git clone <repository-url>
cd <repository-folder>

text

### 2. Install dependencies

Install dependencies separately for frontend and backend:

Install backend dependencies

cd backend
npm install
Install frontend dependencies

cd ../frontend
npm install

text

### 3. Run the development servers

Open two terminal windows or tabs. Run the backend and frontend servers separately.

In the first terminal, start backend server

cd backend/src/server
npm run dev



In the second terminal, start frontend server

cd frontend
npm run dev



### Notes

- Make sure you have Node.js and npm installed.
- The backend server runs from `backend/src/server` directory.
- The frontend server runs from `frontend` directory.
